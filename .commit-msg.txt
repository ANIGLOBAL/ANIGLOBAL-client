Add the developer portal site

Static portal for app builders, published to GitHub Pages from docs/ so it is
served at aniglobal.github.io/ANIGLOBAL-client/.

Pages, all in English
- index.html    portal home: the three-step flow, what the API gives you, and
                an honest status table
- ANIVIET.html  create an app: the fixed registration flow and how to handle
                the client key, marked not open until registration is built
- docs.html     full API reference: base URL, authentication, AGQL grammar,
                directives, canonical IDs, response format, errors, rate limits

The ANIGLOBAL brand site is linked from a parent bar on every page, since this
is the developer half rather than the front door.

App registration and POST /v1/agql are not built, so the portal says so
instead of faking a signup form. Nothing is mocked.

tools/check-portal.mjs verifies every page exists, internal links resolve,
lang="en" is set, each page marks itself current in the nav, the parent bar is
present, and nothing points at the old ANIGLOBAL_API name.
