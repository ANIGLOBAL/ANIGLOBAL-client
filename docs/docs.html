API reference

ANIGLOBAL API

One endpoint, one query language, one credential pair. This is the full reference — base URL, authentication, AGQL grammar, resources, response format, rate limits and error codes.

Create an app Portal home
Under development. POST /v1/agql is not open yet. This documents the intended contract so you can build against it now, and so the implementation has something concrete to satisfy.

Base URL

https://api.aniglobal.com/v1

Region data is served from an edge adapter. The ASIA region currently answers from the ANIVIET dataset.

EndpointMethodPurpose
/v1/agqlPOSTRun an AGQL query.
/v1/healthGETRegion availability. No credentials required.

Authentication

Every request must identify which registered app is calling.

POST https://api.aniglobal.com/v1/agql
Authorization: Bearer <app-client-key>
X-ANIGLOBAL-Client-ID: <app-client-id>
Content-Type: application/json

{ "query": "AGQL -> ASIA @locale(\"vi-VN\") { anime(search: \"Frieren\") { id title } }" }
Server-side only. Never ship the client key in a frontend bundle, and never pass it in a URL. Query strings leak into server logs, browser history and analytics tools.

AGQL

ANIGLOBALQL is ANIGLOBAL's own query syntax. It is not GraphQL, even though the shape looks familiar.

Header

AGQL -> ASIA @locale("vi-VN") { ... }

Region is named with ->, then optional directives. In v1 the region defaults to ASIA.

Language

Locale is a directive, not a separate platform. The same entity is available in vi-VN or en:

AGQL -> ASIA @locale("en") { anime(id: "ag_anime_1") { title } }

Root fields

RootArgumentsReturns
animeid, searchOne anime.
mangaid, searchOne manga.
characterid, searchOne character.
staffid, searchOne staff member.

Relation traversal

-> follows a relation. It is part of the language, not an implementation detail:

AGQL -> ASIA @locale("vi-VN") {
  anime(search: "Frieren") {
    id title cover
    -> characters @merge   { id name image }
    -> staff      @fallback { id name role }
    -> studio                { id name }
  }
}

Directives

DirectiveWherePurpose
@locale("vi-VN")Query headerLanguage for localised fields.
@smartRoot fieldLet ANIGLOBAL pick the best available source per field.
@mergeRelationMerge records from several sources into one.
@fallbackRelationUse only when no better source has it.

Canonical IDs

Public records use ANIGLOBAL IDs. Slugs and upstream provider IDs are never exposed, so they can change without breaking your app. 

ag_anime_1
ag_manga_1
ag_character_1
ag_staff_1

Response format

{
  "data": {
    "anime": {
      "id": "ag_anime_1",
      "title": "Frieren: Beyond Journey's End",
      "characters": [
        { "id": "ag_character_1", "name": "Frieren" }
      ]
    }
  }
}

Relations come back as arrays even when a single record is expected, so a missing relation is an empty array rather than a missing key.

Errors

Errors use a stable code so your app can branch on them.

{
  "error": {
    "code": "INVALID_CLIENT_KEY",
    "message": "The provided App Client credentials are invalid."
  }
}
CodeMeaning
AGQL_PARSE_ERRORThe query could not be parsed.
AGQL_VALIDATION_ERRORParsed, but not a valid query.
RESOURCE_NOT_FOUNDNo record with that canonical ID.
PLATFORM_NOT_AVAILABLEThat region has no dataset yet.
CLIENT_ID_REQUIREDMissing the client ID header.
INVALID_CLIENT_IDNo such registered app.
INVALID_CLIENT_KEYThe secret did not match.
CLIENT_REVOKEDThe app was revoked.
INSUFFICIENT_SCOPEThe app lacks the required permission.
RATE_LIMITEDToo many requests for this app client.

Rate limits

Counted per app client, not per IP.

HeaderMeaning
X-RateLimit-LimitRequests allowed in the window.
X-RateLimit-RemainingRequests left in the window.
X-RateLimit-ResetUnix time the window resets.
Retry-AfterSeconds to wait, on a 429.

Back off on 429 using Retry-After. Do not retry in a tight loop.

Example

curl -X POST https://api.aniglobal.com/v1/agql \
  -H "Authorization: Bearer $ANIGLOBAL_CLIENT_KEY" \
  -H "X-ANIGLOBAL-Client-ID: $ANIGLOBAL_CLIENT_ID" \
  -H "Content-Type: application/json" \
  -d '{"query":"AGQL -> ASIA @locale(\"vi-VN\") { anime(search: \"Frieren\") @smart { id title } }"}'
