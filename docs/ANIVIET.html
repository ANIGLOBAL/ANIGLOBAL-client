Create an app

Get your
credentials.

Registering an app gives you a client ID and a client key. That pair is what identifies your requests, and what gets revoked if you ever need to rotate it.

Registration is not open yet. App registration is still being built, so this page cannot issue credentials right now. You can still read the full documentation and build against the intended contract. Nothing is faked here.

What you will do

The flow is fixed. It opens without a waiting list.

Sign in with your ANIVIET account

One login for the whole ANI network. There is no separate ANIGLOBAL account to create or verify.

Name the application

Something your team will recognise later, because this is what shows up on the app list and in logs.

Choose a scope

Scopes limit what the key can reach, so a read-only app never holds write access.

Copy the client key once

The key is shown a single time. Store it in your secret manager, never in a browser bundle or a URL.

Your account

Apps are managed from your ANIVIET account, where the developer section already points here.

ANIVIET account

Open the account page, then the developer section. That is where your apps will be listed.

Existing accounts only — no new signup needed

Read the docs first

Authentication headers, AGQL syntax, resources, directives and error codes.

Recommended before you register

Handling the key safely

Keep it server-side

A key in a frontend bundle is a public key. Route every API call through your own backend.

Never put it in the URL

Query strings leak into server logs, browser history and analytics tools.

One key per environment

Separate keys for development and production, so staging traffic cannot exhaust your production quota.

Rotate by revoking

Each app client is revocable on its own. Revoking one does not disturb any of your other apps.
