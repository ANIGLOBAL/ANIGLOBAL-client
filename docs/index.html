How it works

Three moving parts, and you only ever touch two of them.

1  Register

Register an app and receive a client ID and client key. Each app is separate and revocable on its own.

2  Authenticate

Send the key in an Authorization header, server-side. Keys are never passed in a URL.

3  Query

Post AGQL to /v1/agql and get JSON back. Upstream sources stay hidden.

What you get

Every region, one endpoint

Adding a region to ANIGLOBAL does not add an endpoint for you to learn. Region is chosen inside the query.

Language is a parameter

Ask for vi-VN or en on the same entity. Language does not define a separate platform.

Stable IDs

Every record has a canonical ag_ ID. Upstream slugs and provider IDs are never part of the contract.

Per-app rate limits

Quota is counted per app client, so a noisy integration cannot starve anyone else's app.
